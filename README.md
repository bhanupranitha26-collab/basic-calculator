# Basic Calculator Web App

A simple calculator built using **HTML, CSS, and JavaScript**.  
Supports addition, subtraction, multiplication, division, decimal, backspace, and clear.

## Features
- Clean UI with CSS Grid
- Keyboard support (Enter, Backspace, numbers, operators)
- Real-time display updates
- Error handling using try/catch

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
Just open `index.html` in any browser, or use VS Code Live Server.
